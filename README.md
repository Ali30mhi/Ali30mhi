# Hi, I'm Ali 👋

Student developer building small, polished tools, for students and for developers in Iran.
I enjoy low-level work (interpreters, VMs) and mixing software with hardware.

### 🧭 [rahyab](https://github.com/Ali30mhi/rahyab)
One command to make pip, npm, go, docker and apt work in Iran, even during an
internet shutdown. Tests mirrors for real, skips outdated ones, and every change
can be undone. Single binary for Linux, macOS and Windows.
`Go`

### 🌍 [Earthquake Globe](https://github.com/Ali30mhi/earthquake-globe) · [live demo](https://ali30mhi.github.io/earthquake-globe/)
Real-time 3D globe of USGS earthquake data back to 1900, plus a home-made
ESP32 seismic sensor. Persian/English, works offline.
`JavaScript` `three.js` `ESP32`

### 🚇 [Tehran Metro 3D](https://github.com/Ali30mhi/tehran-metro-3d) · [live demo](https://ali30mhi.github.io/tehran-metro-3d/)
Interactive 3D map of the Tehran Metro on a city map, with animated trains and
station search. Built from OpenStreetMap data.
`JavaScript` `three.js`

### ⏱️ [Darsyar](https://github.com/Ali30mhi/Darsyar) · [live](https://ali30mhi.github.io/Darsyar/)
Persian study timer with streaks, a 12-week heatmap and shareable progress
cards. One HTML file, no sign-up.
`HTML` `CSS` `JavaScript`

### 🧮 [forth-interpreter](https://github.com/Ali30mhi/forth-interpreter)
A Forth interpreter in C with a small VM, colored REPL and turtle graphics
in the terminal.
`C`
